# 🚶 Walk Goal Tracker

A simple Java application that calculates total daily steps from morning, noon, and evening walks, and evaluates the user's activity level using conditional logic (`if-else`).

---

## 📌 Features

* Calculates the total steps across three daily walking sessions.
* Evaluates activity tiers based on step milestones:
  * **7,000+ steps:** 🏃 Active & Healthy!
  * **4,000–6,999 steps:** 🚶 Nice Movement!
  * **Under 4,000 steps:** 🚶 Go For A Short Walk!
* Outputs total step count and activity level to the console.
