📖 Big O Notation
A Java program that demonstrates different time complexities (Big-O Notation) using practical algorithms. This project serves as a learning guide — showing how runtime grows with input size across constant, logarithmic, linear, quadratic, cubic, exponential, factorial, and square root complexities.

✨ Features
O(1) Constant → Accessing first element, checking even numbers

O(log n) Logarithmic → Binary search in sorted arrays

O(n) Linear → Finding max, summing array elements

O(n log n) Linearithmic → Merge sort implementation

O(n²) Quadratic → Bubble sort, duplicate pair detection

O(n³) Cubic → Matrix multiplication, 3-sum problem

O(2ⁿ) Exponential → Recursive Fibonacci, subset generation

O(n!) Factorial → Generating all permutations

O(√n) Square Root → Prime number checking
